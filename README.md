# VCL Clarity Scoreboard

A live-updating leaderboard widget that pulls data from your Notion AVWAP Stats and Trade Log v2, computes leaders across 8 metrics, and renders as a card grid you can embed inline on the VCL Clarity Notion page.

## What you get

A scoreboard that shows:
- 👑 Best AVWAP × Methodology combo (headline)
- 🏆 Top Cumulative R
- 🎯 Top Win Rate (≥5 trades)
- 📊 Most Trades
- ⚡ Top Expectancy
- 💥 Biggest Single Trade
- ⚓ Best AVWAP
- 🎮 Best Methodology

Auto-refreshes every 30 minutes via GitHub Actions. You can also trigger a refresh manually.

## Setup (one-time, ~20 minutes)

### 1. Create a Notion integration

1. Go to https://www.notion.so/my-integrations
2. Click **+ New integration**
3. Name: `VCL Clarity Scoreboard`. Workspace: your CRYPTO POTUS workspace. Capabilities: **Read content** AND **Update content** (the second one is required so the script can scrub stale relations on each refresh).
4. Click **Save**, then copy the **Internal Integration Secret** (starts with `secret_` or `ntn_`)

### 2. Share the databases with the integration

In Notion, open each of these:
- **AVWAP Stats** (the database, not the inline view)
- **Trade Log v2**

For each: click **...** (top right) → **Connections** → search for `VCL Clarity Scoreboard` → click to add.

### 3. Push this folder to a new GitHub repo

```bash
cd ~/Documents/Paladin/Paladin/Obsidian/PaladinV0/scoreboard
git init
git add .
git commit -m "Initial scoreboard"
gh repo create vcl-clarity-scoreboard --public --source=. --push
```

(Or do it through github.com manually: create a new public repo, drag-and-drop these files, commit.)

### 4. Add the Notion token as a repo secret

1. On your repo's GitHub page, go to **Settings → Secrets and variables → Actions → New repository secret**
2. Name: `NOTION_TOKEN`
3. Value: paste the secret you copied in step 1
4. Click **Add secret**

### 5. Enable GitHub Pages

1. **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main`, Folder: `/ (root)`
4. Save

Your widget URL will be: `https://<your-github-username>.github.io/vcl-clarity-scoreboard/`

### 6. Trigger the first data refresh

1. **Actions** tab → **Refresh scoreboard data** workflow → **Run workflow** → **Run workflow**
2. Wait ~30 seconds for it to complete
3. Refresh the GitHub Pages URL — you should see real data

### 7. Embed in Notion

1. Open VCL Clarity in Notion
2. Type `/embed` and paste the GitHub Pages URL
3. Resize the embed block as needed (300–500px tall works well)

Done. The scoreboard will auto-refresh every 30 minutes. To force a refresh, run the workflow manually from the Actions tab.

## Files

- `index.html` — the widget itself. Reads `data.json` and renders cards.
- `data.json` — cached scoreboard data, regenerated by GitHub Actions.
- `refresh.js` — Node script that queries Notion and writes `data.json`.
- `.github/workflows/refresh.yml` — GitHub Action that runs the script on a 30-minute schedule.

## Configuration

**Database IDs** are hardcoded in `refresh.js`:
- AVWAP Stats: `92b9ba93-1e73-4533-bede-c70f7e7a492e`
- Trade Log v2: `edba84db-7e45-4f54-8b23-d8d7c9059c6e` (the inline-view block id on VCL Clarity)

If you ever rebuild those databases, update the IDs at the top of `refresh.js`.

**Refresh frequency** is in `.github/workflows/refresh.yml` as `cron: '*/30 * * * *'`. Change to `'*/15 * * * *'` for every 15 min, etc. GitHub Actions free tier gives plenty of headroom for this.

**Min trades for Win Rate ranking** is `MIN_TRADES_FOR_WR = 5` in `refresh.js`. This prevents a single-trade winner from showing 100% WR.

## Troubleshooting

**Widget shows "Couldn't load scoreboard"** → `data.json` is missing or the page is loading from cache. Check the Actions tab for failures, and try a hard reload.

**Action fails with "Could not find database"** → The integration isn't shared with that database. Re-do step 2 of setup.

**Widget shows old data** → Last GitHub Action run failed or hasn't fired yet. Check the Actions tab. Or just trigger a manual refresh.

**Action fails with "401 Unauthorized"** → `NOTION_TOKEN` secret is missing or wrong. Re-do step 4.
